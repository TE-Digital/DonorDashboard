# Data Policy and Privacy Statement

## Purpose
This project is open-sourced to promote transparency, collaboration, and reuse for educational and social-impact purposes.  
While the source code is publicly available, **data is not**.

This policy clarifies how data must be handled when using, deploying, or extending this software.

---

## No Production Data Included
This repository **does not contain**:
- Real student data
- Real donor data
- Real teacher or school data
- Personal identifiers of any kind
- Authentication credentials or API keys

Any sample data provided is **synthetic** and for demonstration purposes only.

---

## Personal Data and Minors
This software may be used in contexts involving:
- Children or minors
- Teachers and school staff
- Donors and volunteers

Anyone deploying this software is **solely responsible** for ensuring that:
- Personal data is collected lawfully
- Appropriate consent has been obtained
- Special protections for minors are applied
- Data minimization principles are followed

---

## Data Protection and Legal Compliance
Users of this software are responsible for compliance with all applicable data protection laws, including but not limited to:
- Thailand Personal Data Protection Act (PDPA)
- General Data Protection Regulation (GDPR), where applicable
- Local education and child-protection regulations

The authors and maintainers of this project **do not act as data controllers or processors** for any third-party deployments.

---

## Prohibited Content
Under no circumstances should the following be committed to this repository:
- Real personal data
- Student names, photos, or identifiers
- Donor names or financial records
- GPS coordinates or precise location data linked to individuals
- Authentication secrets, tokens, or passwords

Any pull request containing such data will be rejected.

---

## Security Expectations
Users deploying this software are expected to:
- Secure their own infrastructure
- Use proper access controls and authentication
- Protect backups and logs
- Implement encryption where appropriate

This project is provided **"as is"**, without warranty or guarantee of fitness for a particular purpose.

---

## Data Breaches and Vulnerabilities
If you discover a security issue or data protection concern related to this project:
- Do **not** disclose it publicly
- Report it responsibly via the contact method listed in `SECURITY.md` (or the repository maintainers)

---

## Ethical Use
This software is intended to support education, social development, and humanitarian initiatives.

The maintainers strongly discourage use for:
- Surveillance or profiling
- Discrimination or exclusion
- Exploitation of vulnerable groups
- Any activity that violates human rights or data protection principles

---

## Summary
- Open source code does **not** mean open data
- No real personal data belongs in this repository
- Deployers are responsible for legal and ethical compliance
- The maintainers assume no liability for third-party deployments
