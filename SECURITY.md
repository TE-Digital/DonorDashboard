# Security Policy

## Purpose
The security of this project is taken seriously, particularly because it may be used in contexts involving:
- Children and minors
- Educational institutions
- Donors and volunteers
- Personal and sensitive data

This document describes how to report security issues responsibly.

---

## Supported Versions
Only the latest version of the code in the main branch is actively maintained.

Older versions may not receive security updates.

---

## Reporting a Vulnerability
If you discover a security vulnerability or data protection concern:

**Please do not report it publicly.**

Instead:
- Contact the maintainers privately via email:
  
  **contact@icarethailand.com**

(Replace this address with an appropriate project or organization contact.)

Please include:
- A clear description of the issue
- Steps to reproduce, if applicable
- Potential impact (e.g. data exposure, privilege escalation)
- Any relevant logs or screenshots (avoid sharing real personal data)

---

## Responsible Disclosure
We ask that you:
- Give the maintainers reasonable time to investigate and respond
- Avoid exploiting the issue beyond what is necessary to demonstrate it
- Refrain from public disclosure until a fix or mitigation is available

We aim to acknowledge reports promptly and handle them responsibly.

---

## Data Protection Considerations
Security issues involving:
- Personal data
- Student information
- Donor records
- Authentication or access control

are treated with **high priority**.

Please note:
- This repository contains no real production data
- Deployers are responsible for securing their own infrastructure
- The maintainers are not data controllers for third-party deployments

---

## Scope
This security policy applies to:
- Source code in this repository
- Configuration examples included here

It does **not** cover:
- Third-party services (e.g. hosting providers, databases, authentication services)
- Custom deployments or forks
- Infrastructure operated by others

---

## Disclaimer
This project is provided **“as is”**, without warranty of any kind.  
The maintainers cannot guarantee that all security issues will be identified or resolved.

---

## Thank You
Responsible security reporting helps protect users, contributors, and the communities served by this project.

Thank you for helping to keep this project safe.
