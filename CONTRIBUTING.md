# Contributing Guidelines

Thank you for your interest in contributing to this project!  
Contributions from students, volunteers, and developers are welcome and appreciated.

This document explains how to contribute responsibly and safely.

---

## Who Can Contribute
We welcome contributions from:
- Students
- Volunteers
- NGO partners
- Developers interested in social-impact technology

You do **not** need to be an expert to contribute — documentation improvements, bug reports, and small fixes are valuable.

---

## Code of Conduct
All contributors are expected to:
- Be respectful and inclusive
- Communicate constructively
- Respect cultural and social differences
- Act in line with the project’s educational and humanitarian goals

Harassment or inappropriate behavior will not be tolerated.

---

## What You Can Contribute
Examples of useful contributions:
- Bug fixes
- Code improvements or refactoring
- Documentation improvements
- Accessibility enhancements
- UI/UX improvements
- Tests
- Translations

If you are unsure, open an issue and ask.

---

## What You Must NOT Contribute
Do **not** include:
- Real student, donor, or teacher data
- Personal names, photos, or identifiers
- Credentials, API keys, or secrets
- Production database dumps
- Proprietary or copyrighted material without permission

Pull requests containing such content will be rejected.

---

## How to Contribute
1. Fork the repository
2. Create a feature branch (`feature/your-feature-name`)
3. Make your changes
4. Ensure the project builds and tests pass
5. Submit a pull request with a clear description

Please explain **why** the change is useful, not just **what** you changed.

---

## Style and Quality
- Follow existing code style and structure
- Keep changes focused and minimal
- Write clear commit messages
- Comment complex logic where helpful

This is an educational project — clarity matters more than cleverness.

---

## Licensing of Contributions
By submitting a contribution:
- You confirm that the work is your own
- You agree that your contribution is licensed under the **Apache License 2.0**
- You grant the maintainers the right to use, modify, and redistribute your contribution as part of the project

---

## Review Process
- Maintainers will review pull requests on a best-effort basis
- Feedback may be provided for improvements
- Approval may take time, especially during academic or holiday periods

Please be patient — this is a community-driven project.

---

## Questions and Support
If you have questions:
- Open an issue
- Ask for clarification
- Request guidance before starting large changes

We are happy to help contributors learn and grow.

---

## Thank You
Your contribution helps support education and social impact.
Thank you for taking the time to contribute responsibly.
